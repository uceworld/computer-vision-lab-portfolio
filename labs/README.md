# Published Labs

This repository is a curated portfolio, not a mirror of the private coursework workspace.

The directories below are scope placeholders only. They contain no completed experiment claims or unreviewed solutions. Replace each placeholder with a release only after the private implementation has been executed, inspected, sanitized and explicitly approved for publication.

Every published lab should include:
- a concise explanation of the problem and method;
- student-authored, reviewed source code or a sanitized notebook;
- permitted input assets and provenance/licence information;
- a tested environment and reproducible run command;
- genuine outputs, figures and result tables;
- verification notes, failure cases and limitations.

Do not publish lecturer-owned decks, original assessment templates, private source packs, personal identifiers, credentials or unapproved assessed work. See docs/release-checklist.md.
