# Computer Vision Lab Portfolio

A curated portfolio of reproducible computer-vision experiments and explanations developed alongside coursework.

## Scope

- NumPy image-array fundamentals
- Image colour spaces and geometric transformations
- Histograms and histogram equalisation
- Edge detection, contours, and Hough line/circle detection
- An interactive OpenCV final-project application

## Publication status

Repository scaffolding only. No experiment is represented as completed until its code has been run and its evidence reviewed. Content is added only after checking course assessment rules, authorship, privacy, and source licences.

## Reproducibility

Each published item should state its objective, source of input images, environment, command to run, algorithm parameters, actual outputs, limitations, and verification steps. Do not include lecturer-owned slide decks, original assignment templates, private project instructions, secrets, or unapproved assessment solutions.

See `docs/methodology.md`, `docs/reproducibility.md`, and `docs/image-assets.md`.
