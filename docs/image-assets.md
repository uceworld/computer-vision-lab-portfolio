# Image Asset Policy

Use self-generated synthetic geometry for deterministic algorithm tests. A premium AI-generated showcase image can be used for presentation, but cannot be the only detector test because generated geometry may be inconsistent. An openly licensed photograph is also acceptable if source, creator, licence and attribution are recorded.

Each asset needs a manifest entry with filename, dimensions, intended use, source/generation note, licence/provenance and SHA-256. Do not publish lecturer slide images, textbook figures or other copyrighted assets without permission.
