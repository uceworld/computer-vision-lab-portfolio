# Methodology

Each published experiment should state:
1. The question or task.
2. Source and licence/provenance of input images.
3. Python/OpenCV/NumPy environment and reproducible command.
4. Algorithm and important parameters.
5. Actual outputs and interpretation.
6. Verification checks, failure cases and limitations.

Prefer a simple baseline before optional complexity. Explain RGB/BGR conventions, image dtype/range, threshold choices and geometric assumptions. Do not publish claims unsupported by retained execution evidence.
